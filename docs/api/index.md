# API Reference

Welcome to the Canvas React API reference. Here you can find detailed information about the components and core classes provided by the engine.

## Components

- [`Canvas`](./canvas.md): The root component that sets up the stage.
- [`Group`](./group.md): A container for grouping shapes.
- [`Layer`](./layer.md): A performance-optimized layer component.
- [Shapes](./shapes.md): Built-in shapes like Rect, Circle, and Path.

## Core API

- [Node](./node.md): The base class for all scene objects.
- [Timeline](./timeline.md): Orchestrate complex animations.
- [Tween](./tween.md): Basic property-based animations.
